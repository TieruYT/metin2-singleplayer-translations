يضم هذا المستودع نصوص **Metin2 Singleplayer** - عميل اللعبة، وأسماء العناصر
والوحوش، ورسائل الخادم، والمهام، ودردشة البوتات، ومشغل Windows، ولوحة الويب الكلاسيكية - حتى يتمكن
اللاعبون من ترجمة اللعبة إلى لغتهم. يحتوي على الترجمات فقط، ولا يحتوي على أي
شيفرة للعبة.

يُفحص كل pull request تلقائيًا، وتدخل الترجمات المقبولة إلى اللعبة في
الإصدارات التالية.

## ما الموجود هنا

| المجلد | المحتوى |
|---|---|
| `template/` | جميع نصوص اللعبة، مع عمود `translation` فارغ. نقطة البداية للغة جديدة. |
| `de/` `fr/` `pt/` `ro/` `tr/` | اللغات الموجودة في اللعبة مع ترجمتها الحالية: صحّحها وأكمل الناقص (الأسطر ذات `status` `new`). |
| `hu/` `es/` `it/` `cs/` `nl/` `da/` `el/` `ru/` `ar/` `ko/` | لغات جديدة، مترجمة بالكامل بمساعدة الذكاء الاصطناعي: نرجو من الناطقين بها تصحيح ما يبدو خاطئًا. |
| `en_US/` | الإنجليزية الأمريكية: النص الإنجليزي المصدر (بالتهجئة البريطانية) بالتهجئة الأمريكية (color، armor، defense...). |
| `tools/validate.py` | الفحص الذي يمر به كل pull request. |

الإنجليزية هي المصدر، والبولندية معروضة بجانبها للمرجع؛ ولا تملك أي منهما
مجلدًا خاصًا.

يحتوي كل مجلد لغة على ملفات CSV نفسها، مقسمة إلى أجزاء ليتمكن GitHub من
عرضها وتحريرها (700 سطر كحد أقصى لكل ملف):

| الملفات | المحتوى |
|---|---|
| `1_klient_NN.csv` | العميل: النوافذ والأزرار والتلميحات والمهارات والقواعد |
| `2_przedmioty_potwory_NN.csv` | أسماء العناصر والوحوش وأوصاف العناصر |
| `3_gra_serwer_NN.csv` | رسائل الخادم الخاصة (الدردشة وأسطر النظام) |
| `4_questy_NN.csv` | حوارات المهام |
| `5_boty_czat_NN.csv` | دردشة البوتات وثرثرة الوحوش وعبارات الخادم |
| `6_launcher_NN.csv` | مشغل Windows |
| `7_panel_NN.csv` | لوحة الويب الكلاسيكية (لوحة الإدارة على المنفذ 7788، في المتصفح) |

لكل ملف الأعمدة التالية:

| العمود | |
|---|---|
| `id` | مفتاح السطر. **لا تغيّره أبدًا.** |
| `english` | النص المطلوب ترجمته. **لا تغيّره أبدًا.** |
| `polski` | النص نفسه بالبولندية، للمرجع (قد يكون فارغًا). |
| `translation` | **ترجمتك - العمود الوحيد الذي تحرره.** فارغ = تعرض اللعبة النص الإنجليزي. |
| `notes` | أين يظهر النص، وما يجب الحفاظ عليه، وحد الطول. |
| `status` | `new` (غير مترجم)، `done` (مترجم)، `check` (مثل الإنجليزي - راجعه). يمكنك جعله `done`. |

## كيف تترجم

### أ. في المتصفح (تعديلات صغيرة)

1. افتح الملف، مثلًا [`ar/1_klient_01.csv`](ar/1_klient_01.csv). يعرضه GitHub
   كجدول؛ استخدم مربع البحث فوقه للعثور على سطر.
2. انقر على القلم (**Edit this file**). في المرة الأولى ينشئ GitHub نسخة
   (fork) لك.
3. غيّر عمود `translation` فقط في الأسطر التي تريدها. النص الذي يحتوي على
   فاصلة أو علامة اقتباس أو سطر جديد يوضع بين علامتي اقتباس مزدوجتين
   (`"هكذا، مثلًا"`)؛ وتُكتب علامة الاقتباس داخله مرتين (`""`).
4. انقر **Commit changes...** ثم **Propose changes** ثم **Create pull
   request**. اكتب في جملة واحدة ما الذي ترجمته.

### ب. في جدول بيانات (أسطر كثيرة)

1. نزّل الملفات (افتح ملفًا، **Download raw file**؛ أو الزر الأخضر **Code**،
   **Download ZIP**، للكل).
2. افتحها في برنامج جداول بيانات:
   - **Google Sheets**: ملف > استيراد > تحميل. يعمل دون إعدادات.
   - **LibreOffice Calc**: افتح الملف؛ اختر ترميز **UTF-8** والفاصل
     **فاصلة**، واجعل الأعمدة من نوع **نص**.
   - **Excel**: لا تنقر نقرًا مزدوجًا على الملف (سيقرأ Excel الحروف بشكل
     خاطئ). استخدم بيانات > من نص/CSV، أصل الملف **65001: Unicode (UTF-8)**،
     المحدِّد **فاصلة**. احفظ بصيغة **CSV UTF-8 (محدد بفاصلة)**.
3. املأ عمود `translation`. لا تغيّر أسماء الملفات، ولا تضف أعمدة أو تحذفها،
   ولا تغيّر `id` و`english`. الفرز والتصفية لا بأس بهما.
4. احفظ بصيغة CSV (UTF-8، مفصول بفواصل) بالاسم نفسه.
5. على GitHub افتح مجلد اللغة، **Add file > Upload files**، اسحب ملفاتك، ثم
   **Propose changes** و**Create pull request**.

لا يلزمك ترجمة كل شيء دفعة واحدة - أرسل ما لديك.

## القواعد

1. **عمود `translation` فقط.** يبقى `id` و`english` كما هما؛ ويرفض الفحص أي
   ملف تم تغييرهما فيه.
2. **احتفظ بكل متغير وكل رمز تمامًا كما في الإنجليزية وبالترتيب نفسه** -
   فاللعبة هي التي تملؤها:
   - متغيرات printf: `%s` `%d` `%u` `%ld` `%.1f` `%5d` ... و`%%` (علامة النسبة المئوية)؛
   - العناصر النائبة: `{0}` `{#0}` `{name}` `{skrot}` ...؛
   - `[ENTER]` سطر جديد في نافذة المهمة؛ و`[WAIT]` و`[DELAY value;5]`
     و`[COLOR r;1|g;0|b;0]` أوامرها؛
   - الألوان `|cffff0000` ... `|r`، والروابط `|H` ... `|h`، `|E` ... `|e`.

   يمكنك نقلها داخل الجملة كما تقتضي لغتك، لكن يجب أن تبقى المتغيرات من نوع
   `%` بالترتيب نفسه. النص بين قوسين معقوفين مثل `[Guild]` أو `[PT]` نص
   عادي: ترجمه.
3. **الحروف.** ترسم اللعبة كل لغة بصفحة ترميز واحدة من Windows، لذلك لا
   يمكن عرض إلا حروفها - لا رموز تعبيرية، ولا رموز مثل `→` أو `✓`:

   | صفحة الترميز | اللغات | الحروف |
   |---|---|---|
   | 1250 | pl, cs, sk, hu, ro, hr, sl, sr (لاتينية), bs, sq | ą ć ę ł ń ó ś ź ż, á č ď é ě í ň ř š ť ú ů ý ž, ő ű, ă â î ş ţ |
   | 1251 | ru, uk, bg, be, mk, sr (كيريلية) | а б в г д ... я, є і ї ґ, ў, ђ ј љ њ ћ џ |
   | 1252 | de, fr, es, it, pt, nl, da, sv, no, fi, ca, id ... | à á â ã ä å æ ç è é ê ë ì í î ï ñ ò ó ô õ ö ø ù ú û ü ß œ |
   | 1253 | el | α β γ δ ... ω, ά έ ή ί ό ύ ώ |
   | 1254 | tr, az | ç ğ ı İ ö ş ü, â î û |
   | 1257 | lt, lv, et | ā č ē ģ ī ķ ļ ņ š ū ž, ą ę ė į ų |

   العربية تستخدم صفحة الترميز 1256. الرومانية: صفحة الترميز فيها **ş ţ
   بالسيديلا** فقط، وليس ș ț بالفاصلة. المشغل (`6_launcher_*`) برنامج Windows
   مستقل ويقبل أي حرف. وكذلك لوحة الويب (`7_panel_*`)، وهي صفحة في
   المتصفح: كلاهما **UTF-8**، أي حرف من أي لغة.
4. **دردشة البوتات** (الأسطر التي تقول ملاحظاتها "ASCII letters only"): تكتب
   البوتات مثل اللاعبين، بحروف لاتينية بسيطة a-z دون علامات.
5. **الطول.** حيث تقول الملاحظات "max N characters"، لا يوجد في اللعبة مكان
   لأكثر من ذلك.
6. **الأسطر الجديدة** فقط حيث توجد في الإنجليزية أو حيث تقول الملاحظات "new
   lines allowed".
7. **لوحة الويب** (`7_panel_*`): نصوصها تدخل صفحة ويب، لذا احتفظ بوسوم HTML
   الإنجليزية كما هي تمامًا (`<b>`، `</b>`، `<a href="...">`، `<br>`، والعناصر
   النائبة من نوع `<number>` بين قوسين زاويين)، ولا تضف `<` أو `>` أو `javascript:`
   من عندك. متغيراتها `%s` و`%d` و`%(name)s` و`{name}`؛ ويجوز نقل `%(name)s`
   المسمّى. و`%` يليه مسافة (`25% a character`) هو علامة نسبة مئوية. تظهر اللغة
   التي تُرجم فيها نص واحد على الأقل من اللوحة في اختيار لغة اللوحة؛ وما لم يُترجم
   يظهر بالإنجليزية.

## لغة جديدة

1. انسخ مجلد `template/` كاملًا إلى مجلد يحمل رمز ISO 639-1 المكون من حرفين
   للغتك (`hu`، `es`، `cs`، `pl`... - انظر
   [القائمة](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes)).
   يمكنك فعل ذلك في جدول بيانات: نزّل `template/`، ترجم، ثم ارفع الملفات إلى
   المجلد الجديد (**Add file > Upload files**، واكتب `xx/` قبل الاسم لإنشاء
   المجلد).
2. ترجم وافتح pull request.

تحتاج اللغة الجديدة إلى بعض العمل في اللعبة قبل أن يتمكن اللاعبون من
اختيارها (اللغات خارج صفحة الترميز 1250 تحتاج أيضًا إلى عميل جديد)، لذلك قد
تصل بعد بضعة إصدارات من أول ترجمة.

## الفحص

يشغّل كل pull request الملف `tools/validate.py` (GitHub Actions). وهو يبلّغ،
عند السطر الذي وجد فيه المشكلة، عن:

- `id` غير موجود في `template/`، أو مكرر؛
- عمود `english` تم تغييره؛
- متغيرات أو عناصر نائبة أو وسوم أو رموز ألوان مختلفة عن الإنجليزية؛
- في ورقة لوحة الويب، وسوم HTML غير التي في الإنجليزية، أو `<` أو `>` أو
  `javascript:` من عنده؛
- حرف خارج صفحة ترميز اللغة، أو علامة جدولة، أو حرف تحكم، أو سطر جديد حيث لا
  يُسمح به، أو نص طويل جدًا.

لا يُحكم إلا على الأسطر التي غيّرها pull request الخاص بك؛ أما المشكلات
الموجودة مسبقًا في الملفات فتُحصى ولا تُحسب عليك. لتشغيله بنفسك (Python 3،
دون تثبيت أي شيء): `python tools/validate.py ar`.
