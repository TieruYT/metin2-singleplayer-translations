# Metin2 Singleplayer - μεταφράσεις της κοινότητας

[English](README.md) | [Polski](README_PL.md) | [Türkçe](README_TR.md) | [Deutsch](README_DE.md) | [Français](README_FR.md) | [Español](README_ES.md) | [Italiano](README_IT.md) | [Português](README_PT.md) | [Română](README_RO.md) | [Magyar](README_HU.md) | [Nederlands](README_NL.md) | [Čeština](README_CS.md) | [Dansk](README_DA.md) | **Ελληνικά** | [Русский](README_RU.md) | [العربية](README_AR.md) | [한국어](README_KO.md)

Αυτό το αποθετήριο περιέχει τα κείμενα του **Metin2 Singleplayer** - τον
πελάτη του παιχνιδιού, τα ονόματα αντικειμένων και τεράτων, τα μηνύματα του
διακομιστή, τις αποστολές, τη συνομιλία των bots, τον εκκινητή για Windows και τον κλασικό πίνακα ιστού
- ώστε οι παίκτες να μπορούν να μεταφράσουν το παιχνίδι στη γλώσσα τους.
Περιέχει μόνο μεταφράσεις: κανέναν κώδικα του παιχνιδιού.

Κάθε pull request ελέγχεται αυτόματα, και οι εγκεκριμένες μεταφράσεις
μπαίνουν στο παιχνίδι στις επόμενες εκδόσεις.

## Τι υπάρχει εδώ

| φάκελος | περιεχόμενο |
|---|---|
| `template/` | όλα τα κείμενα του παιχνιδιού, με κενή τη στήλη `translation`. Η αφετηρία μιας νέας γλώσσας. |
| `de/` `fr/` `pt/` `ro/` `tr/` | οι γλώσσες που έχει ήδη το παιχνίδι, με την τρέχουσα μετάφρασή τους: διόρθωσέ τη και συμπλήρωσε ό,τι λείπει (γραμμές με `status` `new`). |
| `hu/` `es/` `it/` `cs/` `nl/` `da/` `el/` `ru/` `ar/` `ko/` | νέες γλώσσες, πλήρως μεταφρασμένες με τη βοήθεια AI: όσοι τις μιλάτε ως μητρική, διορθώστε ό,τι ακούγεται λάθος. |
| `en_US/` | αμερικανικά αγγλικά: το αγγλικό κείμενο πηγής (βρετανική ορθογραφία) σε αμερικανική ορθογραφία (color, armor, defense...). |
| `tools/validate.py` | ο έλεγχος από τον οποίο περνά κάθε pull request. |

Τα αγγλικά είναι η πηγή και τα πολωνικά εμφανίζονται δίπλα ως αναφορά· καμία
από τις δύο δεν έχει δικό της φάκελο.

Κάθε φάκελος γλώσσας περιέχει τα ίδια αρχεία CSV, χωρισμένα σε τμήματα ώστε
το GitHub να μπορεί να τα εμφανίζει και να τα επεξεργάζεται (το πολύ 700
γραμμές ανά αρχείο):

| αρχεία | περιεχόμενο |
|---|---|
| `1_klient_NN.csv` | ο πελάτης: παράθυρα, κουμπιά, επεξηγήσεις, ικανότητες, κανόνες |
| `2_przedmioty_potwory_NN.csv` | ονόματα αντικειμένων και τεράτων, περιγραφές αντικειμένων |
| `3_gra_serwer_NN.csv` | τα μηνύματα του ίδιου του διακομιστή (συνομιλία, γραμμές συστήματος) |
| `4_questy_NN.csv` | οι διάλογοι των αποστολών |
| `5_boty_czat_NN.csv` | η συνομιλία των bots, η φλυαρία των τεράτων, οι φράσεις του διακομιστή |
| `6_launcher_NN.csv` | ο εκκινητής για Windows |
| `7_panel_NN.csv` | ο κλασικός πίνακας ιστού (ο πίνακας διαχείρισης στη θύρα 7788, στον browser) |

Κάθε αρχείο έχει τις στήλες:

| στήλη | |
|---|---|
| `id` | το κλειδί της γραμμής. **Μην το αλλάξεις ποτέ.** |
| `english` | το κείμενο προς μετάφραση. **Μην το αλλάξεις ποτέ.** |
| `polski` | το ίδιο κείμενο στα πολωνικά, ως αναφορά (μπορεί να είναι κενό). |
| `translation` | **η μετάφρασή σου - η μόνη στήλη που επεξεργάζεσαι.** Κενή = το παιχνίδι δείχνει τα αγγλικά. |
| `notes` | πού φαίνεται το κείμενο, τι πρέπει να διατηρηθεί, ένα όριο μήκους. |
| `status` | `new` (αμετάφραστο), `done` (μεταφρασμένο), `check` (ίδιο με τα αγγλικά - έλεγξέ το). Μπορείς να το ορίσεις σε `done`. |

## Πώς να μεταφράσεις

### A. Στον browser (μικρές αλλαγές)

1. Άνοιξε το αρχείο, π.χ. [`el/1_klient_01.csv`](el/1_klient_01.csv). Το
   GitHub το δείχνει ως πίνακα· χρησιμοποίησε το πεδίο αναζήτησης από πάνω για
   να βρεις μια γραμμή.
2. Πάτησε το μολύβι (**Edit this file**). Την πρώτη φορά το GitHub φτιάχνει
   ένα αντίγραφο (fork) για σένα.
3. Άλλαξε μόνο τη στήλη `translation` των γραμμών που θέλεις. Ένα κείμενο με
   κόμμα, εισαγωγικά ή αλλαγή γραμμής μπαίνει σε διπλά εισαγωγικά
   (`"έτσι, για παράδειγμα"`)· τα εισαγωγικά μέσα του γράφονται δύο φορές
   (`""`).
4. Πάτησε **Commit changes...**, μετά **Propose changes** και μετά **Create
   pull request**. Γράψε με μια πρόταση τι μετέφρασες.

### B. Σε υπολογιστικό φύλλο (πολλές γραμμές)

1. Κατέβασε τα αρχεία (άνοιξε ένα αρχείο, **Download raw file**· ή το πράσινο
   κουμπί **Code**, **Download ZIP**, για όλα).
2. Άνοιξέ τα σε υπολογιστικό φύλλο:
   - **Google Sheets**: Αρχείο > Εισαγωγή > Μεταφόρτωση. Λειτουργεί χωρίς
     ρυθμίσεις.
   - **LibreOffice Calc**: άνοιξε το αρχείο· διάλεξε σύνολο χαρακτήρων
     **UTF-8**, διαχωριστικό **κόμμα** και όρισε τις στήλες ως **Κείμενο**.
   - **Excel**: μην κάνεις διπλό κλικ στο αρχείο (το Excel θα διάβαζε λάθος
     τα γράμματα). Χρησιμοποίησε Δεδομένα > Από κείμενο/CSV, προέλευση
     αρχείου **65001: Unicode (UTF-8)**, οριοθέτης **Κόμμα**. Αποθήκευσε ως
     **CSV UTF-8 (οριοθετημένο με κόμματα)**.
3. Συμπλήρωσε τη στήλη `translation`. Μη μετονομάσεις τα αρχεία, μην
   προσθέσεις ή αφαιρέσεις στήλες και μην αλλάξεις τα `id` και `english`. Η
   ταξινόμηση και το φιλτράρισμα είναι εντάξει.
4. Αποθήκευσε ως CSV (UTF-8, με κόμματα) με το ίδιο όνομα.
5. Στο GitHub άνοιξε τον φάκελο της γλώσσας, **Add file > Upload files**,
   σύρε τα αρχεία σου, μετά **Propose changes** και **Create pull request**.

Δεν χρειάζεται να τα μεταφράσεις όλα μονομιάς - στείλε ό,τι έχεις.

## Κανόνες

1. **Μόνο η στήλη `translation`.** Τα `id` και `english` μένουν όπως είναι·
   ο έλεγχος απορρίπτει αρχείο στο οποίο άλλαξαν.
2. **Κράτα κάθε μεταβλητή και κάθε κώδικα ακριβώς όπως στα αγγλικά, με την
   ίδια σειρά** - τα συμπληρώνει το παιχνίδι:
   - μεταβλητές printf: `%s` `%d` `%u` `%ld` `%.1f` `%5d` ... και `%%` (ένα σύμβολο ποσοστού)·
   - θέσεις: `{0}` `{#0}` `{name}` `{skrot}` ...·
   - το `[ENTER]` είναι αλλαγή γραμμής σε παράθυρο αποστολής· τα `[WAIT]`,
     `[DELAY value;5]`, `[COLOR r;1|g;0|b;0]` είναι οι εντολές του·
   - χρώματα `|cffff0000` ... `|r`, σύνδεσμοι `|H` ... `|h`, `|E` ... `|e`.

   Μπορείς να τα μετακινήσεις μέσα στην πρόταση όπως χρειάζεται η γλώσσα σου,
   αλλά οι μεταβλητές τύπου `%` πρέπει να μείνουν με την ίδια σειρά. Ένα
   κείμενο σε αγκύλες όπως `[Guild]` ή `[PT]` είναι κανονικό κείμενο:
   μετάφρασέ το.
3. **Γράμματα.** Το παιχνίδι σχεδιάζει κάθε γλώσσα σε μία κωδικοσελίδα των
   Windows, οπότε μόνο τα γράμματά της μπορούν να εμφανιστούν - όχι emoji,
   όχι σύμβολα όπως `→` ή `✓`:

   | κωδικοσελίδα | γλώσσες | γράμματα |
   |---|---|---|
   | 1250 | pl, cs, sk, hu, ro, hr, sl, sr (λατινικά), bs, sq | ą ć ę ł ń ó ś ź ż, á č ď é ě í ň ř š ť ú ů ý ž, ő ű, ă â î ş ţ |
   | 1251 | ru, uk, bg, be, mk, sr (κυριλλικά) | а б в г д ... я, є і ї ґ, ў, ђ ј љ њ ћ џ |
   | 1252 | de, fr, es, it, pt, nl, da, sv, no, fi, ca, id ... | à á â ã ä å æ ç è é ê ë ì í î ï ñ ò ó ô õ ö ø ù ú û ü ß œ |
   | 1253 | el | α β γ δ ... ω, ά έ ή ί ό ύ ώ |
   | 1254 | tr, az | ç ğ ı İ ö ş ü, â î û |
   | 1257 | lt, lv, et | ā č ē ģ ī ķ ļ ņ š ū ž, ą ę ė į ų |

   Ρουμανικά: η κωδικοσελίδα έχει μόνο **ş ţ με υποστιγμή**, όχι ș ț με
   κόμμα. Ο εκκινητής (`6_launcher_*`) είναι ξεχωριστό πρόγραμμα των Windows
   και δέχεται οποιοδήποτε γράμμα. Το ίδιο και ο πίνακας ιστού (`7_panel_*`), μια σελίδα
   στον browser: και τα δύο είναι **UTF-8**, κάθε γράμμα κάθε γλώσσας.
4. **Η συνομιλία των bots** (γραμμές των οποίων τα notes λένε "ASCII letters
   only"): τα bots γράφουν σαν παίκτες, με απλά λατινικά γράμματα a-z χωρίς
   τόνους.
5. **Μήκος.** Όπου τα notes λένε "max N characters", το παιχνίδι δεν έχει
   χώρο για περισσότερα.
6. **Αλλαγές γραμμής** μόνο όπου τις έχουν τα αγγλικά ή όπου τα notes λένε
   "new lines allowed".
7. **Ο πίνακας ιστού** (`7_panel_*`): τα κείμενά του μπαίνουν σε ιστοσελίδα,
   οπότε κράτα τις ετικέτες HTML των αγγλικών ακριβώς όπως είναι (`<b>`, `</b>`,
   `<a href="...">`, `<br>` και τις θέσεις τύπου `<number>` σε γωνιακές
   αγκύλες) και μην προσθέτεις δικά σου `<`, `>` ή `javascript:`. Οι μεταβλητές
   του είναι `%s`, `%d`, `%(name)s` και `{name}`· ένα επώνυμο `%(name)s` μπορεί
   να μετακινηθεί. Ένα `%` που ακολουθείται από κενό (`25% a character`) είναι
   σύμβολο ποσοστού. Μια γλώσσα με τουλάχιστον ένα μεταφρασμένο κείμενο του
   πίνακα εμφανίζεται στην επιλογή γλώσσας του· ό,τι δεν έχει μεταφραστεί
   εμφανίζεται στα αγγλικά.

## Μια νέα γλώσσα

1. Αντίγραψε ολόκληρο τον φάκελο `template/` σε φάκελο με τον διψήφιο κωδικό
   ISO 639-1 της γλώσσας σου (`hu`, `es`, `cs`, `pl`... - δες
   [τη λίστα](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes)).
   Γίνεται και σε υπολογιστικό φύλλο: κατέβασε το `template/`, μετάφρασε και
   ανέβασε τα αρχεία στον νέο φάκελο (**Add file > Upload files**, γράψε `xx/`
   μπροστά από το όνομα για να δημιουργηθεί ο φάκελος).
2. Μετάφρασε και άνοιξε ένα pull request.

Μια νέα γλώσσα χρειάζεται λίγη δουλειά στο παιχνίδι πριν μπορέσουν να τη
διαλέξουν οι παίκτες (οι γλώσσες εκτός της κωδικοσελίδας 1250 χρειάζονται και
νέο πελάτη), οπότε μπορεί να έρθει μερικές εκδόσεις μετά την πρώτη μετάφραση.

## Ο έλεγχος

Κάθε pull request εκτελεί το `tools/validate.py` (GitHub Actions). Αναφέρει,
στη γραμμή όπου το βρήκε:

- ένα `id` που δεν υπάρχει στο `template/`, ή υπάρχει δύο φορές·
- μια αλλαγμένη στήλη `english`·
- άλλες μεταβλητές, θέσεις, ετικέτες ή κωδικούς χρώματος από τα αγγλικά·
- στο φύλλο του πίνακα ιστού, άλλες ετικέτες HTML από τα αγγλικά, ή δικό του
  `<`, `>` ή `javascript:`·
- ένα γράμμα εκτός της κωδικοσελίδας της γλώσσας, ένα tab, έναν χαρακτήρα
  ελέγχου, μια αλλαγή γραμμής όπου δεν επιτρέπεται, ένα πολύ μεγάλο κείμενο.

Κρίνονται μόνο οι γραμμές που άλλαξε το pull request σου· τα προβλήματα που
υπήρχαν ήδη στα αρχεία μετριούνται, αλλά δεν χρεώνονται σε σένα. Για να τον
εκτελέσεις μόνος σου (Python 3, τίποτα για εγκατάσταση):
`python tools/validate.py el`.
