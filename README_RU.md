# Metin2 Singleplayer - переводы сообщества

[English](README.md) | [Polski](README_PL.md) | [Türkçe](README_TR.md) | [Deutsch](README_DE.md) | [Français](README_FR.md) | [Español](README_ES.md) | [Italiano](README_IT.md) | [Português](README_PT.md) | [Română](README_RO.md) | [Magyar](README_HU.md) | [Nederlands](README_NL.md) | [Čeština](README_CS.md) | [Dansk](README_DA.md) | [Ελληνικά](README_EL.md) | **Русский** | [العربية](README_AR.md) | [한국어](README_KO.md)

В этом репозитории собраны тексты **Metin2 Singleplayer** - игрового клиента,
названия предметов и монстров, сообщения сервера, задания, чат ботов, лаунчер для Windows и классическая веб-панель, - чтобы игроки могли перевести игру на свой язык. Здесь
только переводы, игрового кода нет.

Каждый pull request проверяется автоматически, а принятые переводы попадают в
игру в следующих версиях.

## Что здесь есть

| папка | содержимое |
|---|---|
| `template/` | все тексты игры с пустым столбцом `translation`. Отправная точка для нового языка. |
| `de/` `fr/` `pt/` `ro/` `tr/` | языки, которые уже есть в игре, с их текущим переводом: исправь его и допиши недостающее (строки со `status` `new`). |
| `hu/` `es/` `it/` `cs/` `nl/` `da/` `el/` `ru/` `ar/` `ko/` | новые языки, полностью переведены с помощью ИИ: носители языка, исправьте, пожалуйста, то, что звучит неправильно. |
| `en_US/` | американский английский: исходный английский текст (британское написание) в американском написании (color, armor, defense...). |
| `tools/validate.py` | проверка, которую проходит каждый pull request. |

Источник - английский, польский показан рядом для справки; ни у одного из них
нет своей папки.

В каждой языковой папке лежат одни и те же CSV-файлы, разбитые на части, чтобы
GitHub мог их показывать и редактировать (не больше 700 строк в файле):

| файлы | содержимое |
|---|---|
| `1_klient_NN.csv` | клиент: окна, кнопки, подсказки, умения, правила |
| `2_przedmioty_potwory_NN.csv` | названия предметов и монстров, описания предметов |
| `3_gra_serwer_NN.csv` | собственные сообщения сервера (чат, системные строки) |
| `4_questy_NN.csv` | диалоги заданий |
| `5_boty_czat_NN.csv` | чат ботов, болтовня монстров, фразы сервера |
| `6_launcher_NN.csv` | лаунчер для Windows |
| `7_panel_NN.csv` | классическая веб-панель (панель администратора на порту 7788, в браузере) |

В каждом файле есть столбцы:

| столбец | |
|---|---|
| `id` | ключ строки. **Никогда не меняй его.** |
| `english` | текст для перевода. **Никогда не меняй его.** |
| `polski` | тот же текст на польском, для справки (может быть пустым). |
| `translation` | **твой перевод - единственный столбец, который ты редактируешь.** Пусто = игра показывает английский. |
| `notes` | где виден текст, что нужно сохранить, ограничение длины. |
| `status` | `new` (не переведено), `done` (переведено), `check` (как в английском - проверь). Можешь поставить `done`. |

## Как переводить

### A. В браузере (небольшие правки)

1. Открой файл, например [`ru/1_klient_01.csv`](ru/1_klient_01.csv). GitHub
   показывает его как таблицу; строку можно найти через поле поиска над ней.
2. Нажми на карандаш (**Edit this file**). В первый раз GitHub создаст для
   тебя копию (форк).
3. Меняй только столбец `translation` в нужных строках. Текст с запятой,
   кавычками или переводом строки заключён в двойные кавычки
   (`"вот так, например"`); кавычки внутри пишутся дважды (`""`).
4. Нажми **Commit changes...**, затем **Propose changes**, затем **Create pull
   request**. Напиши одним предложением, что ты перевёл.

### B. В электронной таблице (много строк)

1. Скачай файлы (открой файл, **Download raw file**; или зелёная кнопка
   **Code**, **Download ZIP** - для всего сразу).
2. Открой их в электронной таблице:
   - **Google Таблицы**: Файл > Импортировать > Загрузить. Работает без
     настроек.
   - **LibreOffice Calc**: открой файл; выбери кодировку **UTF-8**,
     разделитель **запятая** и задай столбцам тип **Текст**.
   - **Excel**: не открывай файл двойным щелчком (Excel неправильно прочтёт
     буквы). Используй Данные > Из текстового/CSV-файла, источник файла
     **65001: Юникод (UTF-8)**, разделитель **Запятая**. Сохраняй как **CSV
     UTF-8 (разделители - запятые)**.
3. Заполни столбец `translation`. Не переименовывай файлы, не добавляй и не
   удаляй столбцы, не меняй `id` и `english`. Сортировать и фильтровать можно.
4. Сохрани как CSV (UTF-8, через запятую) под тем же именем.
5. На GitHub открой папку языка, **Add file > Upload files**, перетащи файлы,
   затем **Propose changes** и **Create pull request**.

Не обязательно переводить всё сразу - присылай то, что есть.

## Правила

1. **Только столбец `translation`.** `id` и `english` остаются как есть;
   проверка отклонит файл, в котором они изменены.
2. **Сохраняй каждую переменную и каждый код точно как в английском, в том же
   порядке** - их подставляет игра:
   - переменные printf: `%s` `%d` `%u` `%ld` `%.1f` `%5d` ... и `%%` (знак процента);
   - подстановки: `{0}` `{#0}` `{name}` `{skrot}` ...;
   - `[ENTER]` - перевод строки в окне задания; `[WAIT]`, `[DELAY value;5]`,
     `[COLOR r;1|g;0|b;0]` - его команды;
   - цвета `|cffff0000` ... `|r`, ссылки `|H` ... `|h`, `|E` ... `|e`.

   Их можно переставлять внутри предложения, как требует твой язык, но
   переменные вида `%` должны идти в том же порядке. Текст в квадратных
   скобках, например `[Guild]` или `[PT]`, - обычный текст: переведи его.
3. **Буквы.** Игра выводит каждый язык в одной кодовой странице Windows,
   поэтому показать можно только её буквы - никаких эмодзи и символов вроде
   `→` или `✓`:

   | кодовая страница | языки | буквы |
   |---|---|---|
   | 1250 | pl, cs, sk, hu, ro, hr, sl, sr (латиница), bs, sq | ą ć ę ł ń ó ś ź ż, á č ď é ě í ň ř š ť ú ů ý ž, ő ű, ă â î ş ţ |
   | 1251 | ru, uk, bg, be, mk, sr (кириллица) | а б в г д ... я, є і ї ґ, ў, ђ ј љ њ ћ џ |
   | 1252 | de, fr, es, it, pt, nl, da, sv, no, fi, ca, id ... | à á â ã ä å æ ç è é ê ë ì í î ï ñ ò ó ô õ ö ø ù ú û ü ß œ |
   | 1253 | el | α β γ δ ... ω, ά έ ή ί ό ύ ώ |
   | 1254 | tr, az | ç ğ ı İ ö ş ü, â î û |
   | 1257 | lt, lv, et | ā č ē ģ ī ķ ļ ņ š ū ž, ą ę ė į ų |

   Румынский: в кодовой странице есть только **ş ţ с седилью**, а не ș ț с
   запятой. Лаунчер (`6_launcher_*`) - отдельная программа для Windows и
   принимает любые буквы. Как и веб-панель (`7_panel_*`), страница в браузере:
   обе в **UTF-8**, любая буква любого языка.
4. **Чат ботов** (строки, в notes которых написано "ASCII letters only"):
   боты пишут как игроки, простыми латинскими буквами a-z без диакритики.
5. **Длина.** Там, где в notes написано "max N characters", в игре нет места
   для большего.
6. **Переводы строк** только там, где они есть в английском или где в notes
   написано "new lines allowed".
7. **Веб-панель** (`7_panel_*`): её тексты попадают на веб-страницу, поэтому
   сохраняй HTML-теги английского точно как есть (`<b>`, `</b>`,
   `<a href="...">`, `<br>` и подстановки вида `<number>` в угловых скобках) и
   не добавляй своих `<`, `>` или `javascript:`. Её переменные - `%s`, `%d`,
   `%(name)s` и `{name}`; именованную `%(name)s` можно переставлять. `%` с
   пробелом после него (`25% a character`) - знак процента. Язык, в котором
   переведён хотя бы один текст панели, появляется в выборе языка панели; то,
   что не переведено, показывается по-английски.

## Новый язык

1. Скопируй всю папку `template/` в папку с двухбуквенным кодом ISO 639-1
   своего языка (`hu`, `es`, `cs`, `pl`... - см.
   [список](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes)).
   Это можно сделать и в электронной таблице: скачай `template/`, переведи и
   загрузи файлы в новую папку (**Add file > Upload files**, напиши `xx/`
   перед именем, чтобы создать папку).
2. Переведи и открой pull request.

Новому языку нужна некоторая работа в игре, прежде чем игроки смогут его
выбрать (языкам вне кодовой страницы 1250 нужен ещё и новый клиент), поэтому
он может появиться через несколько версий после первого перевода.

## Проверка

Каждый pull request запускает `tools/validate.py` (GitHub Actions). Она
сообщает, в той строке, где нашла проблему:

- `id`, которого нет в `template/`, или который встречается дважды;
- изменённый столбец `english`;
- другие переменные, подстановки, теги или цветовые коды, чем в английском;
- в листе веб-панели другие HTML-теги, чем в английском, или свои `<`, `>`
  или `javascript:`;
- букву вне кодовой страницы языка, табуляцию, управляющий символ, перевод
  строки там, где он запрещён, слишком длинный текст.

Оцениваются только строки, изменённые твоим pull request; проблемы, которые
уже были в файлах, подсчитываются, но тебе не засчитываются. Запустить
самостоятельно (Python 3, ничего не нужно устанавливать):
`python tools/validate.py ru`.
