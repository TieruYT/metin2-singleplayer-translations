# Metin2 Singleplayer - 커뮤니티 번역

[English](README.md) | [Polski](README_PL.md) | [Türkçe](README_TR.md) | [Deutsch](README_DE.md) | [Français](README_FR.md) | [Español](README_ES.md) | [Italiano](README_IT.md) | [Português](README_PT.md) | [Română](README_RO.md) | [Magyar](README_HU.md) | [Nederlands](README_NL.md) | [Čeština](README_CS.md) | [Dansk](README_DA.md) | [Ελληνικά](README_EL.md) | [Русский](README_RU.md) | [العربية](README_AR.md) | **한국어**

이 저장소에는 **Metin2 Singleplayer**의 텍스트 - 게임 클라이언트, 아이템과
몬스터 이름, 서버 메시지, 퀘스트, 봇 채팅, Windows 런처, 클래식 웹 패널 - 가 들어 있어
플레이어가 게임을 자신의 언어로 번역할 수 있습니다. 번역만 들어 있으며 게임
코드는 없습니다.

모든 풀 리퀘스트는 자동으로 검사되며, 승인된 번역은 이후 버전에서 게임에
반영됩니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `template/` | 게임의 모든 텍스트이며 `translation` 열은 비어 있습니다. 새 언어의 시작점입니다. |
| `de/` `fr/` `pt/` `ro/` `tr/` | 게임에 이미 있는 언어와 현재 번역입니다. 수정하고 빠진 부분(`status`가 `new`인 행)을 채워 주세요. |
| `hu/` `es/` `it/` `cs/` `nl/` `da/` `el/` `ru/` `ar/` `ko/` | 새 언어, AI의 도움으로 모두 번역됨: 원어민은 어색한 부분을 고쳐 주십시오. |
| `en_US/` | 미국 영어: 영국식 철자로 된 영어 원문을 미국식 철자로 바꾼 것 (color, armor, defense...). |
| `tools/validate.py` | 모든 풀 리퀘스트가 거치는 검사입니다. |

원문은 영어이며, 폴란드어는 참고용으로 옆에 표시됩니다. 두 언어 모두 별도의
폴더는 없습니다.

각 언어 폴더에는 같은 CSV 파일이 들어 있으며, GitHub에서 보고 편집할 수
있도록 여러 부분으로 나뉘어 있습니다(파일당 최대 700행):

| 파일 | 내용 |
|---|---|
| `1_klient_NN.csv` | 클라이언트: 창, 버튼, 툴팁, 스킬, 규칙 |
| `2_przedmioty_potwory_NN.csv` | 아이템과 몬스터 이름, 아이템 설명 |
| `3_gra_serwer_NN.csv` | 서버 자체 메시지(채팅, 시스템 메시지) |
| `4_questy_NN.csv` | 퀘스트 대화 |
| `5_boty_czat_NN.csv` | 봇 채팅, 몬스터의 대사, 서버 문구 |
| `6_launcher_NN.csv` | Windows 런처 |
| `7_panel_NN.csv` | 클래식 웹 패널 (브라우저에서 여는 7788 포트의 관리자 패널) |

모든 파일의 열은 다음과 같습니다:

| 열 | |
|---|---|
| `id` | 행의 키입니다. **절대 바꾸지 마세요.** |
| `english` | 번역할 텍스트입니다. **절대 바꾸지 마세요.** |
| `polski` | 같은 텍스트의 폴란드어 버전으로, 참고용입니다(비어 있을 수 있음). |
| `translation` | **번역 - 편집하는 유일한 열입니다.** 비어 있으면 게임에 영어가 표시됩니다. |
| `notes` | 텍스트가 표시되는 위치, 유지해야 할 것, 길이 제한입니다. |
| `status` | `new`(미번역), `done`(번역됨), `check`(영어와 같음 - 확인 필요). `done`으로 바꿔도 됩니다. |

## 번역 방법

### A. 브라우저에서(작은 변경)

1. 파일을 엽니다(예: [`ko/1_klient_01.csv`](ko/1_klient_01.csv)). GitHub가 표로
   보여 주며, 위쪽 검색창으로 행을 찾을 수 있습니다.
2. 연필 아이콘(**Edit this file**)을 누릅니다. 처음에는 GitHub가 사본(포크)을
   만들어 줍니다.
3. 원하는 행의 `translation` 열만 바꿉니다. 쉼표, 따옴표, 줄바꿈이 있는
   텍스트는 큰따옴표로 감쌉니다(`"이렇게, 예를 들어"`). 안에 있는 따옴표는 두
   번 씁니다(`""`).
4. **Commit changes...**, **Propose changes**, **Create pull request** 순서로
   누릅니다. 무엇을 번역했는지 한 문장으로 적어 주세요.

### B. 스프레드시트에서(많은 행)

1. 파일을 내려받습니다(파일을 열고 **Download raw file**, 또는 전체는 초록색
   **Code** 버튼의 **Download ZIP**).
2. 스프레드시트에서 엽니다:
   - **Google 스프레드시트**: 파일 > 가져오기 > 업로드. 별도 설정 없이
     작동합니다.
   - **LibreOffice Calc**: 파일을 열고 문자 집합 **UTF-8**, 구분 기호
     **쉼표**를 고른 다음 열을 **텍스트**로 설정합니다.
   - **Excel**: 파일을 두 번 클릭하지 마세요(Excel이 글자를 잘못 읽습니다).
     데이터 > 텍스트/CSV에서, 파일 원본 **65001: 유니코드(UTF-8)**, 구분 기호
     **쉼표**를 사용합니다. **CSV UTF-8(쉼표로 분리)** 형식으로 저장합니다.
3. `translation` 열을 채웁니다. 파일 이름을 바꾸거나 열을 추가·삭제하지 말고,
   `id`와 `english`를 바꾸지 마세요. 정렬과 필터는 괜찮습니다.
4. 같은 이름으로 CSV(UTF-8, 쉼표 구분)로 저장합니다.
5. GitHub에서 언어 폴더를 열고 **Add file > Upload files**로 파일을 끌어다
   놓은 뒤 **Propose changes**와 **Create pull request**를 누릅니다.

한 번에 모두 번역할 필요는 없습니다. 된 만큼 보내 주세요.

## 규칙

1. **`translation` 열만.** `id`와 `english`는 그대로 둡니다. 이 열들이 바뀐
   파일은 검사에서 거부됩니다.
2. **모든 변수와 코드를 영어와 똑같이, 같은 순서로 유지하세요** - 게임이
   채워 넣습니다:
   - printf 변수: `%s` `%d` `%u` `%ld` `%.1f` `%5d` ... 그리고 `%%`(퍼센트 기호);
   - 자리 표시자: `{0}` `{#0}` `{name}` `{skrot}` ...;
   - `[ENTER]`는 퀘스트 창의 줄바꿈이고, `[WAIT]`, `[DELAY value;5]`,
     `[COLOR r;1|g;0|b;0]`는 퀘스트 창의 명령입니다;
   - 색상 `|cffff0000` ... `|r`, 링크 `|H` ... `|h`, `|E` ... `|e`.

   언어에 맞게 문장 안에서 위치를 옮길 수는 있지만, `%` 형식 변수는 같은
   순서를 유지해야 합니다. `[Guild]`나 `[PT]`처럼 대괄호 안의 텍스트는 일반
   텍스트이므로 번역합니다.
3. **글자.** 게임은 각 언어를 하나의 Windows 코드 페이지로 표시하므로 그
   코드 페이지의 글자만 표시할 수 있습니다. 이모지나 `→`, `✓` 같은 기호는
   쓸 수 없습니다:

   | 코드 페이지 | 언어 | 글자 |
   |---|---|---|
   | 1250 | pl, cs, sk, hu, ro, hr, sl, sr(라틴), bs, sq | ą ć ę ł ń ó ś ź ż, á č ď é ě í ň ř š ť ú ů ý ž, ő ű, ă â î ş ţ |
   | 1251 | ru, uk, bg, be, mk, sr(키릴) | а б в г д ... я, є і ї ґ, ў, ђ ј љ њ ћ џ |
   | 1252 | de, fr, es, it, pt, nl, da, sv, no, fi, ca, id ... | à á â ã ä å æ ç è é ê ë ì í î ï ñ ò ó ô õ ö ø ù ú û ü ß œ |
   | 1253 | el | α β γ δ ... ω, ά έ ή ί ό ύ ώ |
   | 1254 | tr, az | ç ğ ı İ ö ş ü, â î û |
   | 1257 | lt, lv, et | ā č ē ģ ī ķ ļ ņ š ū ž, ą ę ė į ų |

   한국어는 코드 페이지 949(CP949)를 사용합니다. 루마니아어: 코드 페이지에는
   **세디유가 붙은 ş ţ**만 있고, 쉼표가 붙은 ș ț는 없습니다. 런처
   (`6_launcher_*`)는 별도의 Windows 프로그램이므로 모든 글자를 쓸 수
   있습니다. 웹 패널(`7_panel_*`)도 브라우저의 페이지이므로 마찬가지입니다:
   둘 다 **UTF-8**이며 어떤 언어의 어떤 글자든 쓸 수 있습니다.
4. **봇 채팅**(notes에 "ASCII letters only"라고 적힌 행): 봇은 플레이어처럼
   악센트 없는 라틴 문자 a-z로만 입력합니다.
5. **길이.** notes에 "max N characters"라고 적힌 곳은 게임에 그보다 긴
   텍스트를 넣을 공간이 없습니다.
6. **줄바꿈**은 영어에 있거나 notes에 "new lines allowed"라고 적힌 곳에서만
   씁니다.
7. **웹 패널**(`7_panel_*`): 텍스트가 웹 페이지에 들어가므로 영어의 HTML 태그를
   그대로 유지하고(`<b>`, `</b>`, `<a href="...">`, `<br>`, 꺾쇠괄호 안의
   `<number>` 같은 자리 표시자) 직접 `<`, `>`, `javascript:`를 추가하지 마십시오.
   변수는 `%s`, `%d`, `%(name)s`, `{name}`이며, 이름 있는 `%(name)s`는 위치를
   옮겨도 됩니다. 뒤에 공백이 오는 `%`(`25% a character`)는 퍼센트 기호입니다.
   패널 텍스트가 하나라도 번역된 언어는 패널의 언어 선택에 나타나며, 번역되지
   않은 부분은 영어로 표시됩니다.

## 새 언어

1. `template/` 폴더 전체를 해당 언어의 두 글자 ISO 639-1 코드 이름의 폴더로
   복사합니다(`hu`, `es`, `cs`, `pl`... -
   [목록](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes) 참고).
   스프레드시트로도 할 수 있습니다. `template/`을 내려받아 번역한 뒤 새
   폴더에 파일을 올립니다(**Add file > Upload files**, 이름 앞에 `xx/`를 쓰면
   폴더가 만들어집니다).
2. 번역하고 풀 리퀘스트를 엽니다.

새 언어는 플레이어가 선택할 수 있게 되기 전에 게임 쪽 작업이 필요합니다
(코드 페이지 1250 외의 언어는 새 클라이언트도 필요합니다). 따라서 첫 번역
이후 몇 버전 뒤에 추가될 수 있습니다.

## 검사

모든 풀 리퀘스트는 `tools/validate.py`(GitHub Actions)를 실행합니다. 문제가
발견된 행에서 다음을 알려 줍니다:

- `template/`에 없거나 두 번 나오는 `id`;
- 바뀐 `english` 열;
- 영어와 다른 변수, 자리 표시자, 태그, 색상 코드;
- 웹 패널 시트에서 영어와 다른 HTML 태그, 또는 직접 넣은 `<`, `>`,
  `javascript:`;
- 해당 언어의 코드 페이지에 없는 글자, 탭, 제어 문자, 허용되지 않는 줄바꿈,
  너무 긴 텍스트.

풀 리퀘스트에서 바꾼 행만 판정하며, 파일에 이미 있던 문제는 개수만 세고
기여자의 책임으로 보지 않습니다. 직접 실행하려면(Python 3, 설치 필요 없음):
`python tools/validate.py ko`.
